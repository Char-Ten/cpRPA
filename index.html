快速开始

只需几步即可集成cpRPA到您的项目中

通过普通script标签引入，也支持cmd amd引入

<script src="path/to/cpRPA.js"></script>

根据所使用的地图类型不同，需要在使用前传入当前地图框架的一些计算方法

设置距离计算方法

cpRPA.setDistanceFn(function(p1, p2) {
  // 以百度地图为例
  return new BMap.Map().getDistance(
    new BMap.Point(p1.lng, p1.lat),
    new BMap.Point(p2.lng, p2.lat)
  );
});

设置经纬度转像素坐标方法

cpRPA.setLatlng2PxFn(function(latlng) {
  // 以百度地图为例
  return map.pointToPixel(new BMap.Point(latlng.lng, latlng.lat));
});

设置像素坐标转经纬度方法

cpRPA.setPx2LatlngFn(function(px) {
  // 以百度地图为例
  return map.pixelToPoint(new BMap.Pixel(px[0], px[1]));
});

执行.setOptions方法，获得计算完的点集

var polylineLatlngs = cpRPA.setOptions({
  polygon: [/*凸多边形顶点点集*/],
  rotate: 0,
  space: 5
});

console.log(polylineLatlngs);

提示

以上配置方法必须在第一个.setOptions方法前设置。

方法文档

完整的API参考和参数说明

setDistanceFn

设置距离计算方法，接收一个函数，必须在第一个.setOptions方法前设置。

cpRPA.setDistanceFn(function(p1, p2) {
  return /*具体地图类型的距离计算方法*/;
});

setLatlng2PxFn

设置经纬度转地图像素坐标的方法，必须在第一个.setOptions方法前设置。

cpRPA.setLatlng2PxFn(function(latlng) {
  return /*具体地图类型的转换方法*/;
});

setPx2LatlngFn

设置地图像素转经纬度坐标的方法，必须在第一个.setOptions方法前设置。

cpRPA.setPx2LatlngFn(function(px) {
  return /*具体地图类型的转换方法*/;
});

setOptions

设置输入参数，返回航线点集

参数 类型 说明
polygon Array 凸多边形的顶点集
rotate Number 航线围绕地块中心点的旋转角度，顺时针为+，逆时针为-
space Number 无人机飞行相邻两条航线距离的一半。例如，无人机翼展为5米，则两条航线之间的合理距离为10米，space值为5

getPolygonArea

获取地块的初略面积，传入多边形地块的顶点经纬度数组，返回数值型面积值，这个面积值不是一个精确值。

var area = cpRPA.getPolygonArea(latlngs);
// 参数: latlngs.<Array>
// 返回: {Number}

getPolylineArea

获取航线扫过的面积

var area = cpRPA.getPolylineArea(latlngs, space);
// 参数: (latlngs.<Array>, space.<Number>)
// 返回: {Number}
